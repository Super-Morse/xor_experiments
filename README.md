# 🔐 Heuristic XOR Cipher Toolkit

A high-performance cryptographic toolkit written in pure Python. It features an interactive stream cipher tool and an automated analytic breaker designed to analyze, brute-force, and decrypt multi-byte XOR-encrypted payloads using ASCII frequency constraints and heuristic pruning techniques.

---

## 🧠 The Cryptographic Challenge

The core engine targets multi-byte XOR encryption schemes. A standard repeating-key XOR cipher applies bitwise operations sequentially:
`Ciphertext[i] = Plaintext[i] ^ Key[i % KeyLength]`

### The Pruning Breakthrough
Instead of a naive brute-force that allocates memory for thousands of garbage strings, the script implements an early-exit pruning mechanism during the key derivation space calculation:
```python
if resulting_value < 32 or resulting_value > 126:
    break
```
By evaluating the output against printable ASCII boundaries (32 to 126), the execution tree drops invalid keys within microseconds, drastically compressing the processing search space.

---

## 🚀 Execution & Verification Setup

This toolkit contains two separate components that work in tandem:

### 1. Interactive Encryption/Decryption (`cipher.py`)
To encrypt a plaintext message or manually decrypt a known integer array via an interactive console interface, execute:
```bash
python3 cipher.py
```
**Usage Flow:**
* Select option `1` to encrypt a standard text string (e.g., `"Morse was here"`) using a custom key (e.g., `"cat"`). The script will output a clean, comma-separated integer byte array dump.
* Select option `2` to manually decrypt a comma-separated array back into readable plaintext using your known key.

### 2. Automated Crypto-Analytic Breaker (`decipher.py`)
To execute the mathematical brute-force algorithm directly against an encrypted stream dump without knowing the key:
1. Save the comma-separated integers generated by `cipher.py` into a file named `encrypted.txt`.
2. Run the breaker script:
```bash
python3 decipher.py
```

The script will automatically execute the key space permutation search, apply statistical linguistic filters based on space character frequency, and output the cracked key along with the recovered plaintext payload.

## 📊 Performance Analysis
- **Key Space Dimension:** For a 3-byte lowercase alphabetic key space ([a-z]^3), the configuration spans 26^3 = 17,576 permutations.
- **Time Complexity:** Average runtime maps to O(N * K) where N represents text byte size and K represents total key search permutations.
- **Space Complexity:** O(M) where M represents verified printable matches, ensuring near-zero heap memory overhead.
